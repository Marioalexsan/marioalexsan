# Welcome to the Hellscape known as my projects

Here's an assorted list of things I've worked and / or contributed on and / or just find cool:

## ATLYSS

- [AtlyssModding](https://github.com/AtlyssModding) - an organization centered around documentation, and maintenance of abandoned mods for ATLYSS
- [ModAudio](https://github.com/Marioalexsan/AtlyssModAudio) - an Unity 2021+ mod for replacing and manipulating game audio, originally made for ATLYSS
- [AFKConfig](https://github.com/Marioalexsan/AtlyssMods/tree/main/AFKConfig) - configure how AFK behaves
- [AllowAnyNames](https://github.com/Marioalexsan/AtlyssMods/tree/main/AllowAnyNames) - allow using Rich Text for player names, and see other people's custom names in multiplayer
- [BetterPrismUI](https://github.com/Marioalexsan/AtlyssMods/tree/main/BetterPrismUI) - improves the health bar UIs (both player and party UI) by adding an indicator for leftover prism health
- [ChatMacros](https://github.com/Marioalexsan/AtlyssMods/tree/main/ChatMacros) - bind buttons to chat messages and commands
- [Observe](https://github.com/Marioalexsan/AtlyssMods/tree/main/Observe) - makes character heads dynamic and interactive for higher immersion, with multiplayer networking included
- [AtlyssGLTF](https://github.com/Marioalexsan/AtlyssGLTF) - MSBuild variant of GLTFast, for use with mods
- [HostModeration](https://github.com/Marioalexsan/AtlyssHostModeration) - server-side mod that adds operator roles in multiplayer and allows them to ban and kick players on behalf of the host; 100% compatible with vanilla clients
- [AtlyssDiscordRichPresence](https://github.com/Marioalexsan/AtlyssDiscordRichPresence) - adds Discord Rich Presence to Atlyss; includes "Join Game" functionality for joining other people that have this mod, and has Linux support included
- [PerfectGuard](https://github.com/Marioalexsan/AtlyssPerfectGuard) - an experimental mod to reduce or prevent Denial of Service attacks caused by malicious packet spam
- [AutoSaver](https://github.com/Marioalexsan/AutoSaver) - backs up save files in a separate location automatically, reducing the likelihood that vanilla or modded issues cause profile losses

## Casualties: Unknown

- [ScavgameTranslationUtils](https://github.com/Marioalexsan/ScavgameTranslationUtils) - a tool for creating custom locales for Casualties: Unknown
- [scavgame-locale](https://github.com/Orsoniks/scavgame-locale) - Romanian localization for the game, and currently acting as a maintainer for the repository (PS: check out the README if you would like to contribute to community translations!)

## Secrets of Grindea

- [ModBagman](https://github.com/Marioalexsan/ModBagman) - an old and unmaintained mod loader and modding API for Secrets of Grindea
  - for anyone that stumbles upon this and wants to use it, I'd suggest replacing the mod loader functionality with BepInEx 6
  - https://github.com/Marioalexsan/ModBagmanMods
  - https://github.com/Marioalexsan/QoLRebalanceMod
- [AutoSplit](https://github.com/Marioalexsan/SoG-AutoSplit) - unmaintained LiveSplit autosplitter for Secrets of Grindea

## Miscellaneous

- [WrenchMan](https://github.com/Marioalexsan/WrenchMan) - a Discord bot that allows analyzing log files from ATLYSS and other Unity games 
- [BepInEx TemplateMod](https://github.com/Marioalexsan/AtlyssTemplateMod) - a template mod to get started with BepInEx 5 modding, oriented for Thunderstore uploads
- [ProjectSilver](https://github.com/Marioalexsan/ProjectSilver) - an old top-down shooter written in C++ as an university project, where you fight waves of enemies in an arena, and fight a boss at the end
- [QuickSilver](https://github.com/Marioalexsan/QuickSilver) - an old top-down multiplayer shooter written in Java as an university project; similar to Project Silver in nature
- [UndertaleDecomp](https://github.com/kittibyte/UndertaleDecomp) - a decompilation of the latest version of UNDERTALE for the Xbox One ported to the latest Gamemaker Studio 2 Beta with many added toggleable enhancements
- [RainWorldSaveEditor](https://github.com/Vultumast/RainWorldSaveEditor) - an unmaintained save editor for Rain World that used to target RainWorld + Downpour before The Watcher was released
- [dotnet-decompiler](https://github.com/Marioalexsan/dotnet-decompiler) - a very crappy "decompiler" for .NET assemblies written in C++ as an university project; very incomplete and lacking features
